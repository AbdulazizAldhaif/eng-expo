## About The Expo

The **Engineering & Technology Innovation Expo** is an annual event held at the **Riyadh International Convention & Exhibition Center** during **April 5-6, 2026**. The expo aims to:

- Showcase **50+ innovative** engineering and technology projects
- Connect students and researchers with leading companies
- Facilitate knowledge exchange through workshops and lectures
- Recognize outstanding projects and achievements

---

## Key Features

### For Visitors
- **Free registration** with electronic ticket (QR Code)
- **OTP verification** system for mobile number confirmation
- **Flexible duration** selection (1 or 2 days)
- **Capacity alerts** (5,000 seats limit)
- **Digital ticket** delivery via SMS

### For Exhibitors (Booth Booking)
- **Instant approval** for academic institutions
- **Review system** for corporate requests
- **Interactive map** for booth selection (15 booths)
- **Automatic notifications** via SMS
- **Project description** submission

### For Administrators
- **Comprehensive dashboard** for registration management
- **Approval/rejection** system for requests
- **Real-time statistics** (total, pending, approved, rejected)

### For Field Organizers (Check-in)
- **QR Code scanner** for electronic tickets
- **Manual entry** alternative for ticket validation
- **Instant verification** of ticket authenticity
- **Attendance tracking** with recent scans history

## Color System (Platform Code Compliant)

```css
--primary:       #1B8354;   /* SA 600 - Saudi Green (main actions) */
--primary-hover: #25935F;   /* SA 500 - Hover states              */
--primary-light: #54C08A;   /* SA 400 - Light backgrounds         */
--accent:        #161616;   /* Black  - Primary text              */
--gray-light:    #E6E6E6;   /* Gray   - Secondary elements        */
--danger:        #DC3545;   /* Red    - Error states              */
```

**Design Philosophy:** Green as the only accent color. Gray for secondary elements. No orange, gold, or warm colors.
